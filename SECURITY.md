# Security Policy

## Versiones Soportadas

| Versión | Soportada          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporte de Vulnerabilidades

Si descubres una vulnerabilidad de seguridad o un fallo en los módulos de Nemesis, te pedimos reportarlo de manera confidencial y responsable:

1. Utiliza la función de [GitHub Private Vulnerability Reporting](https://github.com/glastor-dev/nemesis/security/advisories/new).
2. O envía un correo electrónico a: `glastor.info@gmail.com`.

Por favor, no abras issues públicos sobre vulnerabilidades de seguridad antes de que el equipo haya tenido la oportunidad de publicar un parche o mitigación.

Agradecemos enormemente la labor de los investigadores de seguridad y la comunidad de código abierto.
